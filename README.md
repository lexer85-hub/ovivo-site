# OVIVO Electric

Автономный адаптивный сайт российского бренда электроустановочных изделий OVIVO.

Сайт полностью отделён от Tilda и работает как обычный статический проект без серверной части, сборщика и внешних зависимостей.

## Что реализовано

- адаптивная шапка с навигацией и мобильным меню;
- главный экран с позиционированием бренда OVIVO;
- каталог коллекций и товаров с квадратными изображениями;
- разделы «О компании», «Преимущества», «Новости» и «Где купить»;
- отдельный лаконичный блок с реквизитами ООО «Инсталл»;
- контактный раздел с данными генерального директора, отделов закупок и продаж, а также адресом производства;
- компактный подвал с логотипом и ссылкой «Наверх»;
- единая сетка, согласованные отступы и адаптация для мобильных устройств;
- локальные шрифты и оптимизированные изображения WebP;
- favicon в фирменном стиле OVIVO;
- понятные имена изображений в формате `kebab-case` и относительные пути к ресурсам;
- файл `.nojekyll` для корректной публикации статических ресурсов через GitHub Pages;
- базовая SEO-оптимизация: метаописание, Open Graph, robots и структурированные данные Schema.org;
- плавное появление блоков при прокрутке с учётом настройки `prefers-reduced-motion`.

## Локальный запуск

Сайт можно открыть напрямую через `index.html` или запустить локальный HTTP-сервер:

```bash
python3 -m http.server 8000
```

После запуска сайт будет доступен по адресу `http://localhost:8000`.

## Размещение

Для публикации загрузите всё содержимое проекта в корневую папку хостинга. Главная страница — `index.html`. Подключение к Tilda, база данных и серверная обработка не требуются.
